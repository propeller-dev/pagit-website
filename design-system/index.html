🌊 Parallax & Scroll

Três padrões de movimento acionados por scroll — extraídos diretamente dos DSs analisados. Do CSS puro (Stripe) ao JS mínimo (Neofin/Abacate), com fallback mobile automático.

① Scroll-Driven Animations — Padrão Stripe

O Stripe usa animation: detect-scroll linear; animation-timeline: scroll() para revelar elementos conforme o usuário rola. Zero JavaScript — CSS puro.

}

② Scroll Reveal — Padrão Neofin + Abacate

Neofin usa opacity + translateY 0.8s ease-out. Abacate usa cubic-bezier(0.25, 0.46, 0.45, 0.94) com delay escalonado. IntersectionObserver garante compatibilidade total com todos os browsers.

const io = new IntersectionObserver(entries =>
  entries.forEach(e => e.isIntersecting && e.target.classList.add('visible')),
  { threshold: 0.15 }
);
document.querySelectorAll('[data-reveal]').forEach(el => io.observe(el));

// Padrão Stripe hero-wave — RAF + lerp orgânico
let tx=0, ty=0, cx=0, cy=0;
el.addEventListener('mousemove', e => {
  const r = el.getBoundingClientRect();
  tx = (e.clientX - r.left - r.width/2) * .5;
  ty = (e.clientY - r.top  - r.height/2) * .5;
});
(function raf() {
  cx += (tx-cx) * .07;  cy += (ty-cy) * .07; // lerp
  layers.forEach(l => {
    const s = +l.dataset.speed;
    l.style.transform = `translate(${cx*s}px,${cy*s}px)`;
  });
  requestAnimationFrame(raf);
})();

👥 Humanização & Personas

Diretrizes fotográficas baseadas nas referências (especialmente Stripe e Neofin) para criar empatia e conexão. Foco: Empreendedores digitais, B2B e prestadores de serviço (sem varejo tradicional físico).

Diretrizes de Fotografia (Estilo Pagit)

AtributoO que fazer (Do)O que evitar (Don't)
Ambiente Home offices clean, coworkings modernos, estúdios claros. Lojas tradicionais (padarias, mercadinhos), galpões industriais escuros.
Perfil (Persona) Freelancers, desenvolvedores, consultores, donos de agência, founders. Varejistas com avental, chão de fábrica.
Iluminação & Tom Luz natural, profissional, bright & airy. Trazendo sensação de "sucesso". Fotos escuras, excessivamente amadoras ou estilo "banco de imagens" engessado.
Cores na Composição Toques sutis do nosso verde primário (#059669) em objetos ou paredes ao fundo. Roupas ou fundos saturados em cores concorrentes (muito azul/laranja/vermelho).
